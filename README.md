# ComfyUI-Face-Library

> 把男女共两百余种脸型量化集成的 ComfyUI 角色提示词节点。

`Facial Customization` 是一个 [ComfyUI](https://github.com/comfyanonymous/ComfyUI) 自定义节点：通过下拉框选择「性别 / 年龄组 / 脸型 / 画风 / 光 / 镜头 / 姿态」等维度，自动拼装出完整、精细的角色提示词，直接连接到文生图节点出图。

## ✨ 特性

- **整脸库模式**：`性别 → 类型（非古风/古风）→ 脸型`，一键调用一张完整角色脸，子项自动锁定。
- **自由组合模式**：`妆容(女)/面部(男) / 骨相 / 五官 / 发型 / 识别 / 气质` 六维独立拼配，下拉显示简洁标签、选中后隐式调用完整描述。
- **风格替换菜单**：画风 16 项、光 8 项、镜头 8 项、姿态 8 项，按需替换。
- **三路输出**：正向提示词、负向提示词、选择摘要 JSON。
- **零依赖**：仅使用 Python 标准库，无需安装任何第三方包。

## 📦 安装

1. 克隆到 ComfyUI 的 `custom_nodes/` 目录：

   ```bash
   cd ComfyUI/custom_nodes
   git clone https://github.com/zoe40404/ComfyUI-Face-Library.git
   ```

   或直接下载源码解压到 `custom_nodes/`。

2. 重启 ComfyUI（或点击界面右上角「刷新」）。

3. 在节点菜单 `Character Customization` 分类下找到 **Facial Customization**。

## 🚀 使用

节点共 **16 个输入**，分为「身份」与「风格」两块：

| 区块 | 输入 | 说明 |
|---|---|---|
| 身份 | `mode` | `整脸库`（选一张完整脸）/ `自由组合`（六维独立拼配） |
| 身份 | `gender` / `ftype` / `age_group` / `face` | 整脸库：性别 → 类型 → 年龄组 → 脸型（`age_group` 在非古风过滤年龄段脸、在古风过滤古风年龄组） |
| 身份 | `age_input` | 自由组合专用：填具体年龄（默认 `18`）；填 `0` 或留空则用年龄组；整脸库自动显示「随脸型自动生成」 |
| 身份 | `profession` | 职业：整脸库显示「随脸型自动生成」；自由组合非古风显示「无固定职业」；自由组合古风可选古风职业 |
| 身份 | `makeup` / `bone` / `eye` / `hair` / `anchor` / `temper` | 自由组合：妆容/面部、骨相、五官、发型、识别、气质 六维（仅自由组合显示） |
| 风格 | `style` / `light` | 画风 16 项、光 8 项 |
| 风格 | `camera` / `pose` | 镜头、姿态（`沿用该脸默认` 或替换为菜单项） |

### 整脸库模式

`gender → ftype → face` 选一张完整脸：`age_group` 统一过滤脸型（`ftype=非古风` 过滤年龄段脸，`ftype=古风` 过滤古风年龄组）。选中后六维子项锁定为占位（字段随脸型进入输出）。

### 自由组合模式

`gender → ftype` 决定六维池来源：`ftype=非古风` 用 `age_group`（可选「不限」）过滤非古风字段；`ftype=古风` 用 `age_group` 选古风年龄组（男女各 5 组：男童/女童、少年/少女、男子/女子、中年男人/中年女人、老翁/老妇）。六个维度各自独立选择（下拉为简洁标签，选中后隐式调用完整描述）。

### 常用选项说明

- **`类型`（ftype）**：`非古风` / `古风` 两个脸库，独立切换；整脸库下选脸整脸调用，自由组合下作为六维池来源。
- **`沿用该脸默认`**（镜头/姿态）：使用所选脸型条目自带的镜头/姿态；该选项仅在「整脸库」模式出现，自由组合模式下镜头/姿态直接使用菜单项。
- **`识别`（痣/疤）**：自由组合模式下已拆分到「单个锚点」，选择「无」则不输出该项；整脸库模式保留该脸的完整锚点。
- **`年龄`**：`年龄 + 性别类别`（男童/女童≤12、少年/少女13–18、男子/女子19–35、中年男人/中年女人36–59、老翁/老妇60–90）；古风整脸库为「年龄 + 古装 + 职业」（如 `32岁古装女帝`、`26岁古装男刺客`），古风自由组合为「年龄 + 古装 + 性别类别」（如 `17岁古装少女`）。自由组合输入年龄会自动钳制到所选年龄组范围，选组后自动代入该组最小年龄。

## 📤 输出

| 输出口 | 类型 | 内容 |
|---|---|---|
| `prompt` | STRING | 完整正向提示词（性别/年龄/妆容/骨相/五官/发型/识别/气质/镜头/姿态/画风/光） |
| `negative` | STRING | 默认负向词（防侧脸、防手部崩坏、防性别漂移） |
| `meta` | STRING | 选择摘要 JSON（模式、性别、年龄组、来源编号、风格选择） |

将 `prompt` / `negative` 连接到文生图节点的正向 / 负向输入即可。
